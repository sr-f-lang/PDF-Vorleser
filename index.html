Einstellungen

Stimmen

KI-Stimmen (Piper) klingen natürlicher. Sie werden beim ersten Gebrauch einmal heruntergeladen und funktionieren danach offline. Tippe auf „Testen“, um einen Beispielsatz zu hören.

Fehlt eine Systemstimme? So installierst du sie
  • iPhone/iPad: Einstellungen → Bedienungshilfen → Gesprochene Inhalte → Stimmen → Sprache wählen → Stimme laden.
  • Mac: Systemeinstellungen → Bedienungshilfen → Gesprochene Inhalte → Systemstimme → Systemstimmen verwalten.
  • Windows: Einstellungen → Zeit und Sprache → Sprache → Sprache hinzufügen (Sprachausgabe aktivieren).
  • Android: Einstellungen → Sprache → Text-zu-Sprache → Stimmdaten herunterladen.

Standard und Texterkennung
